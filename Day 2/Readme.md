# Day 2: Tip Calculator

## Project Overview
A Python program that calculates each person's share of a bill, including a selected tip percentage.

### Concepts Learned

* Getting user input with `input()`
* Type conversion using `float()` and `int()`
* Arithmetic operations
* Variables and mathematical expressions
* Rounding numbers using `round()`

### What I Practiced
Using numerical inputs to perform calculations and display the amount each person should pay when splitting a bill.

### Reflection
This project helped me practice working with numbers, converting data types, and translating a real-life problem into a Python program.
