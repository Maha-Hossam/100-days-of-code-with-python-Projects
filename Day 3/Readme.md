# Day 3: Treasure Island 🏝️

## Project Overview

A text-based adventure game where the player makes a series of choices to find a hidden treasure. Different decisions lead to different outcomes.

## Concepts Learned

* Conditional statements: `if`, `elif`, and `else`
* Nested conditional statements
* Logical operators using `or`
* String methods using `.lower()`
* Basic input validation

## What I Practiced

Building a decision-based game, organizing conditions, and controlling the program flow based on user input.

## Reflection

This project helped me understand how conditional logic works and how nested conditions can create different paths in an interactive program.
