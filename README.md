# 100 Days of Python 🐍
Welcome to my 100 Days of Code: The Complete Python Pro Bootcamp journey!
This repository documents my progress throughout the 100-day challenge as I learn Python, practice writing code, and build projects step by step.

### My Goal:
My goal is to strengthen my understanding of Python, improve my problem-solving abilities, and develop my coding skills through consistent practice and hands-on projects.

### 📚 What You'll Find Here
Throughout this journey, I will continuously update this repository with:

* Daily Projects: Python programs and projects I build as I progress through the course. 
* Learning Notes: Key concepts, explanations, and useful information I learn along the way.
* Practice Exercises: Coding challenges and exercises that help reinforce my understanding.
* Progress Updates: My learning progress, improvements, and lessons learned throughout the challenge.

### My Learning Approach
I believe that understanding programming requires more than just watching lessons. It requires writing code, experimenting, solving problems, learning from mistakes, and applying concepts through practical projects.

Through this challenge, I aim to build a strong foundation in Python and gradually develop the skills needed to apply programming to 
scientific computing and computational neuroscience.

This repository will grow with me throughout the 100 days, reflecting my progress, effort, and continuous learning.
