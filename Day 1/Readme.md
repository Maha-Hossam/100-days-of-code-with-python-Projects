# Band Name Generator 
## Project Overview

My first Python project in the 100 Days of Code challenge!

This program generates a potential band name by combining the name of the city where the user grew up with the name of their pet.

## Concepts Learned

* Using `print()` and `input()`
* Variables and storing user input
* String concatenation
* Basic program execution

## What I Practiced

Building a simple interactive program and learning how to collect user input and use it to generate output.

## Reflection

This project introduced me to the basics of Python syntax, variables, and user interaction.
